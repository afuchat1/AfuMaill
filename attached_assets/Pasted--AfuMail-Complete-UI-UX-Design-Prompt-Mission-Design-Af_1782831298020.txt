# AfuMail — Complete UI/UX Design Prompt

## Mission

Design **AfuMail**, a next-generation email application that feels radically modern, calm, and intelligent.

This is **not another Gmail clone**.

The product should establish its own identity with a clean, premium experience that can remain visually relevant for many years.

The interface should feel invisible, allowing users to focus entirely on communication.

---

# Design Principles

The design must feel:

* Minimal
* Silent
* Elegant
* Fast
* Spacious
* Premium
* Professional
* Intelligent
* Calm
* Timeless

Avoid making the UI look playful or overly branded.

No gradients everywhere.

No oversized icons.

No rounded cartoon buttons.

No excessive shadows.

No unnecessary borders.

No noisy cards.

Everything should breathe.

---

# Color System

Primary colors

* White
* Soft Cream (#FAF8F5)
* Light Gray
* Charcoal
* Black

Accent colors only when necessary

* Blue for actions
* Green for success
* Orange for warning
* Red for destructive actions

Color should communicate meaning, not decoration.

---

# Typography

Use modern typography similar in quality to premium productivity software.

Large readable headings.

Medium-weight body text.

Comfortable line spacing.

Excellent readability.

---

# Spacing

Everything should have generous spacing.

Never crowd information.

Every screen should feel open.

Users should never feel overwhelmed.

---

# Motion

Animations should be subtle.

150–250ms transitions.

Smooth fades.

Natural slide transitions.

Soft loading states.

No flashy animations.

---

# Layout Philosophy

The interface should disappear.

Content should become the focus.

The layout should feel like professional desktop software while remaining perfect on mobile.

---

# Mobile First

Design for phones first.

Then adapt naturally to tablets.

Finally expand beautifully to desktop.

Never simply stretch the mobile interface.

Desktop deserves its own optimized layout.

# Visual Identity

AfuMail should become instantly recognizable without relying on heavy branding.

The product should communicate trust through precision, simplicity, spacing, and consistency.

Every screen should feel handcrafted.

Avoid copying Gmail, Outlook, Apple Mail, or any other existing email client. Study modern productivity software for usability, but create an original visual language that becomes uniquely associated with AfuMail.

## Final Design Goal

Deliver a world-class email experience that feels premium from the first launch. Every interaction should reduce cognitive load, every screen should have a clear purpose, and every visual element should justify its existence. The result should be an email application that users enjoy opening every day because it is calm, fast, intelligent, and effortless to use.
