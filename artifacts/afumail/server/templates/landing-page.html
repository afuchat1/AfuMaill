Features

Everything email should be

Built from the ground up for the Afu community — fast, clean, and fully private.

Private by default

Your inbox is yours alone. Row-level security enforced at the database level — no one else can read your messages, not even admins.

Your own address

Get a personal @afuchat.com address. Your username, your identity — recognisable and memorable to everyone in the community.

Lightning fast

Optimised for speed on both iOS and Android. Messages load instantly — compose, send, and receive without waiting.

Works everywhere

Native iOS and Android apps plus a web interface — your AfuMail goes wherever you do, perfectly synced across all your devices.

Built for community

Closed network means zero spam. You only send and receive from people who are part of the Afu community — just like a real neighbourhood mailbox.

OAuth 2.1 sign-in

Let trusted third-party apps use "Sign in with AfuMail" — PKCE-secured, scoped permissions, full token revocation. No passwords shared.

Security

Your data stays yours

Security isn't an afterthought — it's built into every layer of AfuMail.

Row-level security

Every query is scoped to the authenticated user at the database level. No code path can accidentally expose another user's messages.

Closed network

Emails only flow between @afuchat.com accounts. Spam and phishing from outside the network are structurally impossible.

OAuth 2.1 with PKCE

Third-party apps never see your password. Our PKCE-secured OAuth flow keeps credentials on AfuMail — apps only get the scopes you approve.

No tracking

We don't sell data, show ads, or profile our users. AfuMail is funded by the community, for the community.

Developers

Build on AfuMail

Let users sign in with their AfuMail account. Our OAuth 2.1 / OIDC API is open for trusted developers in the community.

GET /api/oauth/authorize

Start the authorization flow. Redirect your user here with client_id, scope, redirect_uri, and a PKCE challenge.

POST /api/oauth/token

Exchange an authorization code for access and refresh tokens. Supports the authorization_code and refresh_token grants.

GET /api/oauth/userinfo

Fetch the authenticated user's profile — name, username, and email — filtered by the scopes granted.

POST /api/oauth/revoke

Revoke an access or refresh token when the user signs out of your app. RFC 7009 compliant.

GET /.well-known/openid-configuration

OIDC discovery document. Standard-compliant OAuth libraries can auto-configure from this endpoint — no manual setup needed.

GET /docs

Full interactive developer documentation. Covers PKCE flow, request/response tables, code samples in JS, Python, and cURL.
